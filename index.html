Mensajes por WhatsApp

El sistema prepara un mensaje con el número de pedido y su importe. Se abre WhatsApp, pero el envío siempre lo confirma la persona. No se envía ningún mensaje automáticamente.

Información de esta versión

Los datos se guardan solamente en este navegador. No hay servidor, pagos, clientes externos ni mensajes automáticos. Al publicar la aplicación, podremos convertirla en PWA con usuarios reales y base de datos compartida.
