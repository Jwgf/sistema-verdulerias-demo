SISTEMA VERDULERÍAS - PRUEBA DEL VERDULERO (VERSIÓN 2)

NOVEDADES
- Pantalla inicial de carga de precios simplificada.
- Al dictar producto y precio, aparece la selección de variedad.
- Al seleccionar, guarda e intenta escuchar el siguiente producto.
- Botón Terminar para detener el dictado.
- Opción táctil y teclado del celular en «Escribir o usar el micrófono del teclado».
- Catálogo oculto inicialmente y desplegable.
- Los pedidos, ofertas y datos del local de la versión anterior se mantienen.

PUBLICAR EN GITHUB PAGES (HTTPS)
1) Creá un repositorio PÚBLICO en GitHub, por ejemplo verdulerias-prueba.
2) Subí el archivo index.html de esta carpeta a la RAÍZ del repositorio.
3) En Settings > Pages, elegí Deploy from a branch, rama main, carpeta /(root). Guardá.
4) Abrí el enlace HTTPS mostrado por GitHub Pages desde Chrome Android.
5) Autorizá el micrófono cuando Chrome lo solicite.

IMPORTANTE
GitHub Pages publica páginas estáticas: esta prueba NO recibe pedidos reales.
Los datos se guardan localmente en cada navegador (localStorage).
No hay que subir credenciales ni datos de clientes al repositorio público.
Chrome para Android no garantiza escucha ininterrumpida: el código intenta
reanudar tras cada producto, pero puede requerir tocar Comenzar nuevamente.
El acceso por voz puede necesitar Internet y compatibilidad del navegador.
