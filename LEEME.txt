SISTEMA VERDULERIAS - V4 - Catalogo ampliado y dictado

Publicar desde PowerShell con Actualizar_Verdulerias_GitHub_v4.ps1.

Esta entrega tiene 440 articulos, variedades y presentaciones
(210 articulos mas que V3).

Pruebas principales:
- "miel 6500 el frasco" => elegir presentacion y guardar precio.
- "miel" => elegir presentacion, indicar precio manualmente y guardar.
- "papines 2300 el kilo" => variedades de papines.
- "aceite de oliva 9500" => aceite por presentacion.
- "quinoa 4800" => variedades de quinoa.
- "cajon" no debe generar un producto erroneo.

Si Chrome entiende otra palabra, la aplicacion mostrara exactamente lo que
transcribio Chrome para diferenciar dictado de reconocimiento de catalogo.

Los precios guardados en este mismo navegador se conservan porque permanece
igual la clave de almacenamiento y los codigos de todos los productos V3.
Los datos son locales: no hay backend ni pedidos reales.
El sitio en GitHub Pages es publico: usar datos de prueba.
